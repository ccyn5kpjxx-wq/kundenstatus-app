# MOS-Direktmiete: Prüfung der Mietbedingungen

**Stand 27.09.2026 · interne Abnahmevorlage · keine Rechts-, Versicherungs- oder Livefreigabe.** Diese Matrix gehört zum [redaktionellen Kundentext](mos-mietbedingungen-entwurf.md). Sie betrifft ausschließlich Hyundai i10 und Hyundai KONA als entgeltliche Selbstfahrer-Mietwagen von **Gärtner GmbH Karosserie + Lack**. Ein Citroën C3, Auto-Abos und manuelle Werkstattmieten gehören nicht in diesen Checkout. Die Version `ENTWURF-2026-09-27-03` darf weder als freigegebener `terms_text` in eine Live-Konfiguration übernommen noch Kunden zur Unterschrift vorgelegt werden.
