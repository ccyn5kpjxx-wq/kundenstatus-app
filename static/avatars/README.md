# Workshop avatar illustrations

Original fictional characters generated with the built-in image_gen tool on 2026-09-28.
Inspired by the approachable illustrated character presentation in Google's Live Avatar announcement:
https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-with-live-avatar/
These are local sprite illustrations, not Google assets or a Gemini Live Avatar integration.

Each transparent PNG has a 2x2 expression grid: resting, speaking A, speaking O, blinking.
CSS displays one tile without modifying the source asset. Expression animation follows
the assistant's speech state, not phoneme-level lip synchronization. Reduced motion is respected.

## Chris prompt

Use case: stylized-concept. Asset type: production animation sprite sheet for a conversational workshop avatar. Create ONE 1024x1024 transparent PNG with exactly FOUR equal 512x512 square frames in a strict 2x2 grid, no gaps or dividers. In every frame the SAME friendly adult male workshop assistant character, chest-up, directly facing camera, identical scale, position, lighting and pose. Premium soft 3D animated illustration with warm human facial features, large but adult expressive brown eyes, short sculpted brown hair, subtle beard, teal work polo shirt, no logos, relaxed professional personality. Inspired by the friendly expressive illustrated virtual characters used in modern conversational avatar interfaces, not a photo and not a child. Hair entirely visible, torso ends exactly at each square's bottom edge. Face center at identical x/y within each tile. Top LEFT: natural slight smile, lips CLOSED, eyes OPEN (rest). Top RIGHT: same character lips parted in small open A speaking shape, eyes OPEN. Bottom LEFT: same character round small O mouth, eyes OPEN. Bottom RIGHT: same closed-mouth resting smile, eyes CLOSED in a blink. Do not move the head or body between frames. Background genuinely transparent in ALL four frames. Clean edges, subtle dimensional shading, appealing warm expression. Absolutely no text, no labels, no frames, no watermark, no extra faces or props.
