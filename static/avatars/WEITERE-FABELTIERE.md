# Drei weitere Fabeltiere

Mit dem eingebauten Bildgenerierungswerkzeug erstellt. Vier Ausdrucksframes pro Sprite, gleicher Aufbau wie die anderen Fabeltiere.

## Verwendete finale Prompts

### phoenix

Create a cute, friendly storybook animal character animation sheet for a talking assistant. Soft polished 3D illustration. Four equal square panels in an exact 2 by 2 grid on a genuinely transparent background. Same single animal bust, front facing, same position and size in all panels. Top left: eyes open, mouth closed smiling. Top right: eyes open, mouth open speaking. Bottom left: eyes open, small rounded open mouth. Bottom right: eyes closed blinking, mouth closed smiling. Head and torso, entire crest and ears safely inside each panel. No lettering, no panel borders, no scenery. The character is a warm orange and golden PHOENIX bird with a swept feather crest, a little yellow beak, soft folded wings and expressive brown eyes. The crest is feathers. Match the friendly fantasy illustration style of the reference.
